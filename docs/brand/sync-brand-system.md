# Sync Comm Systems Brand System

## Tokens

| Token | Value | Use |
| --- | --- | --- |
| Brand primary | `#0457ff` | Primary buttons, active states, links |
| Brand secondary | `#f6b600` | Safety stripe, highlights, caution emphasis |
| Navy | `#001742` | Headers, dark navigation, high-contrast text |
| Ink | `#071326` | Body text |
| Graphite | `#202734` | Secondary dark surfaces |
| Muted | `#536273` | Supporting text |
| Background | `#f7f8fa` | App and website page background |
| Surface | `#ffffff` | Panels, forms, cards |
| Border | `rgba(7, 19, 38, 0.13)` | Lines and input borders |
| Success | `#1d7a46` | Complete/ready |
| Warning | `#a05a00` | Pending/review |
| Danger | `#b42318` | Failed/blocked |

## Typography

- Public site: Barlow body, Oswald display via Google Fonts.
- SyncOS app: Barlow preferred with Arial/Helvetica fallback. Do not commit unlicensed font files.

## Shape and Spacing

- Radius: 6-8 px for cards and controls.
- Buttons: solid primary blue for main actions; white/navy secondary for supporting actions.
- Forms: labeled fields, visible focus states, compact spacing for operational users.

## Status Language

Use operational status, not marketing claims:

- Account Activated
- Onboarding Incomplete
- Ready for Review
- Company Approved
- Mobilization Not Ready
- Inquiry Received
- Under Review

## Application Surfaces Applied

- Login route uses Sync Comm Systems / SyncOS / Telecom Operations Platform.
- Invite acceptance distinguishes Partner Admin onboarding from Foreman field access.
- Partner onboarding and partner shell inherit app tokens.
- Public website navigation adds Login to SyncOS and Become a Partner.
